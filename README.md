# Quick Budg

Quick Budg is an Android application designed to help users manage their budget efficiently. It includes features for tracking transactions, managing subscriptions, and scanning receipts using ML Kit and CameraX.

## Features

- **Transaction Tracking**: Log and categorize your daily expenses.
- **Subscription Management**: Keep track of recurring payments.
- **Receipt Scanner**: Automatically extract merchant names and amounts from receipts using OCR.
- **Budget Configuration**: Set limits and monitor your spending.
- **Holiday Tracking**: Keep track of special events and associated costs.

## Tech Stack

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Database**: Room
- **Camera & OCR**: CameraX and Google ML Kit Text Recognition
- **Architecture**: MVVM

## Getting Started

### Prerequisites

- Android Studio Koala or newer.
- Android SDK 24 or higher.

### Installation

1. Clone the repository.
2. Open the project in Android Studio.
3. Sync the project with Gradle files.
4. Run the application on an emulator or a physical device.
